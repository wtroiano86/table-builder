# Contributing

Read [Contributing to the package](docs/development/contributing.md) for setup and change expectations, [Testing](docs/development/testing.md) for checks, and [Architecture](docs/architecture.md) for internal boundaries.

Agents working in this repository should start with the repository's [AGENTS.md](https://github.com/wtroiano86/table-builder/blob/main/AGENTS.md) and [the contributor agent workflow](docs/development/agent-workflow.md). Consumers integrating the package into an application should use [Getting started](docs/consumers/getting-started.md).

Maintainers preparing a release should follow [Releasing](docs/development/releasing.md).
